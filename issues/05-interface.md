### User Story

Как пользователь, я хочу понятный интерфейс на телефоне и компьютере, чтобы создать QR-код без специальных знаний и мыши.

### Критерии приёмки

- [ ] Названия режимов, полей, кнопок и ошибок отображаются на русском языке.
- [ ] При ширине окна 320 пикселей нет горизонтальной прокрутки; код и управляющие элементы целиком видны по ширине.
- [ ] Режим, поле ввода, генерация и скачивание доступны при навигации клавишами Tab, Shift+Tab, Enter и Space.
- [ ] У каждого поля есть видимая подпись; сообщение об ошибке связано с полем; успешная генерация объявляется вспомогательным технологиям.
- [ ] Приложение открывается без установки и регистрации в средах, перечисленных в TECH-02.

**Связано с ТЗ:** [раздел 4, UI-01–UI-03, и раздел 5, TECH-01–TECH-02](https://github.com/Zefeld/qr-code-generator-srs/wiki/Техническое-задание).
