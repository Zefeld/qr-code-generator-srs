# Задачи для GitHub Issues

Создайте задачи в указанном порядке в новом репозитории, чтобы номера `#1`–`#6` совпали со ссылками в ТЗ. Укажите название из таблицы в поле Title, а содержимое соответствующего файла — в поле описания. Метки назначаются в интерфейсе GitHub после их создания.

| № | Название | Метки | Описание |
|---|---|---|---|
| 1 | Реализовать ввод и проверку ссылки | Аналитика, Разработка | [01-link.md](01-link.md) |
| 2 | Реализовать ввод и проверку текста | Аналитика, Разработка | [02-text.md](02-text.md) |
| 3 | Реализовать генерацию и просмотр QR-кода | Разработка, Тестирование | [03-generation.md](03-generation.md) |
| 4 | Реализовать сохранение QR-кода в PNG | Разработка, Тестирование | [04-download.md](04-download.md) |
| 5 | Подготовить русскоязычный адаптивный интерфейс | Дизайн, Разработка | [05-interface.md](05-interface.md) |
| 6 | Проверить ошибки, приватность и скорость | Тестирование, Документация | [06-quality.md](06-quality.md) |

После создания Issues проверьте, что у каждой задачи есть обратная ссылка на [Wiki](https://github.com/Zefeld/qr-code-generator-srs/wiki/Техническое-задание), а ссылки из Wiki ведут к правильным номерам задач.
