# Генератор QR-кодов для ссылок и текста

Учебный проект по варианту 69: требования, календарный план и прототип приложения.

Цель приложения — создавать QR-код для введённой ссылки или текста, показывать его на экране и сохранять в PNG. Прототип генерирует коды локально в браузере, без отправки содержимого на сервер.

## Лабораторная работа 3 — запуск прототипа

1. Скачайте репозиторий и выполните `python3 -m http.server 8000` в его каталоге.
2. Откройте `http://localhost:8000`, выберите «Ссылка» или «Текст» и нажмите «Создать QR-код».
3. Проверьте изображение и нажмите «Скачать PNG». Файл имеет размер 512 × 512 пикселей.

Допускается до 1000 байт UTF-8; ссылки должны начинаться с `http://` или `https://` и содержать имя хоста. Пробелы в ссылке вызывают ошибку, пробелы и переносы в тексте сохраняются. Данные и QR-код обрабатываются в браузере. Библиотека [qrcode-generator 2.0.4](vendor/README.md) включена в репозиторий.

Для автоматической проверки необходимы Node.js 20+ и Chrome/Chromium: `npm ci && npm test`. Если браузер установлен в нестандартном месте, задайте переменную `CHROME_PATH`. Тесты проверяют границы ввода, работу интерфейса, сохранённый PNG и считывание независимой библиотекой jsQR.

Релиз v1.0.0 — учебный прототип. Проверки на всех устройствах и браузерах из ТЗ и измерение производительности на устройстве с 2 ГБ ОЗУ отдельно не проводились.
