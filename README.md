# Генератор QR-кодов для ссылок и текста

Материалы лабораторной работы № 1 «Разработка и управление требованиями к программному обеспечению». Вариант 69.

Цель приложения — создавать QR-код для введённой ссылки или текста, показывать его на экране и сохранять в PNG. В этой работе описаны требования к приложению; программная реализация не входит в состав лабораторной работы.
