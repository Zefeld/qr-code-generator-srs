# Генератор QR-кодов для ссылок и текста

Материалы лабораторных работ № 1 «Разработка и управление требованиями к программному обеспечению» и № 2 «Планирование проекта и управление командой». Вариант 69.

Цель приложения — создавать QR-код для введённой ссылки или текста, показывать его на экране и сохранять в PNG. В репозитории описаны требования и план будущей разработки; программная реализация пока не выполнялась.
