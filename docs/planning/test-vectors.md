# Набор входных данных для проверки

Строки ниже передаются без преобразования. Для допустимых строк ожидается точное совпадение результата после независимого считывания; ошибочные данные отклоняются до создания QR-кода. Запись `\n` означает символ перевода строки, `\u0001` — управляющий символ.

| Режим | Исходные данные | Ожидание |
|---|---|---|
| Ссылка | `http://example.org` | Допустима; считанная строка совпадает |
| Ссылка | `https://example.org/page?a=1#part` | Допустима; регистр и символы сохранены |
| Ссылка | `ftp://example.org` | Недопустимый протокол |
| Ссылка | `https://` | Отсутствует имя хоста |
| Ссылка | `https://example.org/a b` | Недопустимый пробел |
| Ссылка | `https://example.org/\u0001` | Недопустимый управляющий символ |
| Текст | пустая строка | Отклонить |
| Текст | `  \n ` | Отклонить: только пробельные символы |
| Текст | `  Привет, мир!\n😀  ` | Допустим; пробелы и перевод строки сохранены |
| Текст | `я` × 500 | 1000 байт UTF-8, допустим |
| Текст | `я` × 500 + `x` | 1001 байт UTF-8, отклонить |
| Ссылка | `https://a.co/` + `x` × 987 | 1000 байт, допустима |
| Ссылка | `https://a.co/` + `x` × 988 | 1001 байт, отклонить |

Примеры и граничные проверки находятся также в [автоматических тестах](../../tests/validation.test.js) и [браузерном сценарии](../../tests/browser.test.js).
