# Матрица требований и приёмки

Исполнитель задач: Баринов Кирилл Вадимович (@Zefeld). Указанные проверки — план приёмки; наличие строки не означает, что испытание уже завершено. Сроки, 88 часов, четыре этапа и зависимости приведены в [календарном плане](../../wiki/План-проекта.md).

| Требование | Детализированные задачи | Способ проверки |
|---|---|---|
| FR-01, FR-02 | #12, #13, #14, #16, #26 | Ввести HTTP/HTTPS, неверные адреса и границы длины; проверить сообщения |
| FR-03, FR-04 | #12, #15, #16, #17, #26 | Ввести кириллицу, переносы, пустые и граничные строки |
| FR-05, FR-06 | #11, #18, #19, #27 | Создать код, проверить цвета и поле, независимо считать строку |
| FR-07 | #20, #23, #26 | Изменить ввод и убедиться, что прежний код скрыт и экспорт недоступен |
| FR-08, FR-09 | #21, #22, #27 | Скачать PNG, проверить имя, размеры и декодированное содержимое |
| REL-01 | #17, #20, #23, #26 | Проверить сообщения и сохранность ввода при ошибках |
| REL-02 | #11, #21, #28 | Проверить сетевые запросы при генерации и скачивании |
| REL-03 | #28 | Измерить 20 запусков на оборудовании, определённом в ТЗ |
| UI-01 | #10, #12, #23, #29 | Проверить русские подписи, режимы и сообщения |
| UI-02 | #10, #25, #29 | Проверить отображение при ширине 320 px и на компьютере |
| UI-03 | #10, #24, #29 | Проверить управление с клавиатуры и доступные подписи |
| TECH-01, TECH-02 | #8, #29 | Проверить запуск на заявленных ОС и браузерах |
| TECH-03 | #8, #11, #30 | Проверить статическое размещение, HTTPS и отсутствие серверного API |

Генерация и сохранение происходят в браузере; серверной обработки введённых строк, регистрации и серверного хранения нет. Учебная SQLite-модель из лабораторной №4 не подключена к приложению.
