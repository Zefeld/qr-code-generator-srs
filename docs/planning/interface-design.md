# Макет и состояния интерфейса

Это текстовая схема реализованного интерфейса; расположение и состояния подтверждаются проверкой приложения, а не означают отдельную приёмку во всех браузерах.

## Компьютер

```text
Генератор QR-кодов                      Всё работает в вашем браузере
Создайте QR-код
┌──── Содержимое ────────────────┐ ┌──── Предпросмотр ──────────────┐
│ Что закодировать: Ссылка Текст│ │ QR-код или состояние «Пусто» │
│ Адрес ссылки / Ваш текст      │ │                               │
│ [ поле ввода               ]  │ │ Статус                        │
│ Подсказка и ошибка            │ │ [ Скачать PNG ]               │
│ [ Создать QR-код ]            │ └───────────────────────────────┘
└───────────────────────────────┘
```

## Экран 320 px

Редактор и предпросмотр располагаются вертикально; элементы укладываются в ширину экрана без горизонтальной прокрутки. Сначала размещается форма, за ней результат и кнопка скачивания.

## Состояния

- Пустой ввод: в предпросмотре приглашение ввести данные, скачивание недоступно.
- Ошибка: текст ошибки у поля, содержимое остаётся для исправления.
- Успех: появляется QR-код и доступна кнопка скачивания.
- Изменение ввода или режима: результат скрывается, скачивание отключается до новой генерации.

Видимые подписи связаны с полями; переход по Tab следует порядку элементов страницы. Сообщение об ошибке использует `role=alert`, состояние результата — `role=status` и `aria-live=polite`. Поддержка вспомогательных технологий на всех устройствах требует отдельной проверки.
