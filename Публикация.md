# Состояние публикации лабораторной работы

Публичный репозиторий [Zefeld/qr-code-generator-srs](https://github.com/Zefeld/qr-code-generator-srs) создан. README, копия ТЗ, шесть Issues и пять меток опубликованы. Номера Issues совпадают со ссылками в ТЗ.

Осталось создать первую страницу Wiki. GitHub предоставляет её Git-репозиторий для загрузки файлов после создания начальной страницы через сайт.

1. Откройте [вкладку Wiki](https://github.com/Zefeld/qr-code-generator-srs/wiki) и нажмите **Create the first page**.
2. В поле названия введите `Техническое задание`.
3. Вставьте содержимое файла [wiki/Техническое-задание.md](wiki/Техническое-задание.md) и сохраните страницу.
4. Проверьте, что [страница Wiki](https://github.com/Zefeld/qr-code-generator-srs/wiki/Техническое-задание) открывается и ссылки на Issues `#1`–`#6` ведут к задачам.

После этого ссылка для сдачи работы: `https://github.com/Zefeld/qr-code-generator-srs`.
